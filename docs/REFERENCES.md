- [Alibaba official block-traces README](https://github.com/alibaba/block-traces): dataset schema, access and license attribution. No external code copied.
- [SNIA MSR trace landing page](https://iotta.snia.org/traces/388): acquisition reference; access/terms not verified by the web fetcher.
- [Notion figure-first design note](https://app.notion.com/p/3e1132c5e44381b082d9f5b60f34afe2): each plot must map to a bounded claim.

No external skill script was executed. Core simulation uses the standard library. Figure rendering uses an isolated, pinned matplotlib environment.
