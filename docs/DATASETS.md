# Data access and redistribution

- Alibaba block traces: [official source](https://github.com/alibaba/block-traces). The official README describes January 2020 virtual-disk I/O, remapped device identifiers, access through a survey, and a license link to [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/), verified on 2026-10-20. Attribution belongs to Alibaba Group; see THIRD_PARTY_NOTICES.md. The linked license governs those data and documents, separately from the project source. This repository retains previously archived normalized 100k-request extracts for devices 4, 49 and 740 only in the Hot/Cold evidence archive. Transformation: independent per-device address namespace, timestamps relative to each extract; input hashes are in archived experiment manifests. No user payload bytes are included. Trace metadata is still treated as research data.
- MSR Cambridge: [SNIA source](https://iotta.snia.org/traces/388). The source was inaccessible to the web fetcher (robots restriction), so redistribution permission is UNVERIFIED here. The evaluated MSR extract is absent from this export; no replacement trace was synthesized. Historical summaries remain available. Obtain authorized data and match the archived input SHA-256 before claiming replay.
- Host Hint final: generated controlled synthetic events, seeds 301–305, not Alibaba or MSR traces. Event realization SHA-256 values and frozen selection hash are in archived final_manifest.json. A smoke run uses separate seeds and does not replace final evidence.

Full 140.1 GiB source stream and the 525,559,379-request / 818-device pilot were not rerun in this rebuild. They are historical profile evidence, distinct from 4×100k policy evaluation. Public release stays subject to a separate ownership and dataset review; both new repositories remain private.
